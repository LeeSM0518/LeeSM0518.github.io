# 1. 당신에게 가장 중요한 '단 하나'는 무엇인가

---

> "내가 큰 성공을 거뒀을 때에는 단 하나의 일에만 모든 정신을 집중했다. 그러나 성공이 들쭉날쭉했을 때는 나의 집중력도 여러 군데에 퍼져 있었던 것이다."
{: .prompt-info }


> "탁월한 성과는 당신의 초점을 얼마나 좁힐 수 있느냐와 밀접하게 연결되어 있다."
{: .prompt-info }


# 2. 도미노 효과
---

> "남다른 성과를 얻기 위해선 삶에서 도미노 효과를 만들어 내야 한다."
{: .prompt-info }


> "큰 성공을 거두는 사람들은 매일 우선순위를 새로 정하고 첫 번째 도미노 조각을 찾은 다음, 그것이 넘어질 때까지 있는 힘껏 내리친다."
{: .prompt-info }


> "핵심은 오랜 시간이다. 성공은 연속하여 쌓인다. 단, 한 번에 하나씩이다."
{: .prompt-info }


# 3. 성공은 반드시 단서를 남긴다
---

> "누구도 홀로 성공할 수 없다. 그 누구도."
{: .prompt-info }


> "성공한 사람들의 삶에 '단 하나'의 정신이 계속해서 나타나는 것은 그것이 그 누구도 부인할 수 없는 근본적인 진실이기 때문이다."
{: .prompt-info }


> "성공의 핵심에는 '단 하나'가 자리 잡고 있다. 바로 그 단 하나가 탁월한 성과를 이끌어 내는 시작점이다."
{: .prompt-info }


> "우발적이거나 심지어 의도적인 거짓도 어느 정도 '진실스럽게' 들리기만 한다면 우리가 진실로 받아들이는 모든 현상을 '트루니시스'(truthiness)라고 한다."
{: .prompt-info }


# 4. 모든 일이 다 중요하다
---

> "평등이란 거짓이다. 이것을 첫 번째로 이해하는 것이 곧 모든 훌륭한 의사결정의 기반이 된다."
{: .prompt-info }

> "성공하는 사람들은 언제나 뚜렷한 우선순위를 가지고 일한다."
{: .prompt-info }

> "우리는 할 일 목록 대신 성공 목록을 만들어야 한다. 남다른 성과를 내기 위해 의도적으로 만든 목록 말이다."
{: .prompt-info }

> "주란의 통찰이 훌륭한 이유는 모든 것이 똑같이 중요하지 않음을 깨달았다는 데 있다."
{: .prompt-info }

> "가장 중요한 단 하나에 이르기까지 80/20 법칙을 계속해라!"
{: .prompt-info }

# 5. 멀티태스킹은 곧 능력이다
---

> "멀티태스킹이란 허상이다."
{: .prompt-info }

# 6. 성공은 철저한 자기관리에서 온다
---

> "사실 성공은 단거리 경주다. 건전한 습관이 자리를 잡을 때까지만 자신을 훈련시켜 달리는 단거리 전력질주인 셈이다."
{: .prompt-info }

> "생각보다 훨씬 적은 자기통제력만으로도 성공할 수 있다. 그 이유는 단 하나다. 성공은 옳은 일을 해야 얻는 것이지, 모든 일을 다 제대로 해야 얻을 수 있는 것이 아니기 때문이다."
{: .prompt-info }

> "가장 중요한 일을 주기적으로 하는 법을 알고, 그 결과로 다른 모든 일이 더 쉬워지는 것이다."
{: .prompt-info }

# 7. 의지만 있다면 못할 일은 없다
---

> "의지력이 늘 발휘될 수 있다는 말은 거짓말이다."
{: .prompt-info }

> "의지력의 수명은 정해져 있다."
{: .prompt-info }

> "의지력이 가장 높을 때 가장 중요한 일을 우선으로 처리해야 한다."
{: .prompt-info }

# 8. 일과 삶에 균형이 필요하다
---

> "모든 일에 관심을 쏟으려 하다 보면 그 모든 일에 대한 노력이 부족해진다. 기적은 바로 극단에서 일어난다."
{: .prompt-info }


# A. 나에 대한 질문
---

어떤 것에 초점을 맞출 것인가?

어떻게 도미노 효과를 일으킬 것인가?

누구와 같이 성공할 것인가?

할 일 목록에 우선순위(성공 목록)를 어떻게 세울 것인가?

어떤 좋은 습관을 만들 것인가?

의지력이 가장 높을 때는 언제이며 그때 어떤 일을 할 것인가?
